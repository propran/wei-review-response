# 风格提炼依据

本技能根据用户提供的导师返修批注和文字修订归纳。此分发版本仅保留通用写作模式，不包含源稿、原始批注摘录、本机路径或项目实验记录。它是样本驱动的风格辅助工具，不是导师署名作品，也不代表导师对具体结果的认可。

## 观察与应用

| 可观察的修改倾向 | 可复用规则 | 适用边界 |
|---|---|---|
| 要求针对当前审稿问题作答 | 每段直接回答对应问题 | 复合问题须逐项覆盖 |
| 优先说明做了什么、结果如何 | 行动和结果先于长篇解释 | 未实施的工作不能写成完成 |
| 要求说明究竟改了什么、在哪里 | 提供实际替换文字和可核对位置 | 不编造页行号 |
| 将重复的样本和统计说明移入图注 | 正文解释结果，图注承载完整技术定义 | 审稿人直接问统计和样本时，正文仍直接回答 |
| 减少没有信息增量的赞同和致谢 | 简短合作，用具体动作代替套话 | 不把简洁写成不礼貌或回避问题 |
| 压缩对未研究问题的旁支展开 | 聚焦当前实验与研究目的 | 保留影响结果解释的实质局限 |
| 要求核对实验名称与图文信息 | 相同实验的关键定义保持一致 | 不靠写作惯例推断实验事实 |
| 要求图像、分组与定量一一对应 | 使证据便于阅读和核查 | 不将单幅图的处理建议设为通用规则 |
| 追问数据矛盾的真实原因 | 说清错误性质及核实后的修正 | 未核对前不预设原因 |

## 不应迁移的内容

源稿中的科学推测、疑问、待补实验和暂定措辞不是可继承的事实。工作稿中的拼写错误、口语或残句也不是应模仿的风格。

“表达更直接”是改善组织和措辞，不是增加结论强度；“结果优先”不等于隐去不利结果；“少谈局限”应理解为压缩冗余，而非删除决定结论范围的条件。

## 辅助方法

技能结构参考 `skill-creator`；逐点回应、修改定位及完成状态区分参考 `nature-response`；专业英文的具体主语和精确动词参考 `cheng-wei-paperwriting-style`。这些技能是方法参考，不是本样本的作者归属证据，也不是运行本技能的强制依赖。
