# 魏老师审稿回复风格

`wei-review-response` 是用于英文论文审稿回复的 Codex skill。它根据用户提供的导师返修样本，提炼出直接回答、结果优先、解释适量、修改可追溯的写作方式。

## 适用任务

- 按魏老师的返修风格改写或精简逐点回复。
- 检查回复是否回答原问、是否说明实际修改及位置。
- 区分已经修改的文字、批注建议和待核实事实。

技能强调简洁、客观、合作，同时保留实验条件、证据强度和影响结论的必要限定。它不用于冒充导师、预测导师意见或替代原始数据核验。

## 安装

将本仓库下载到本地，把包含 `SKILL.md`、`agents/` 和 `references/` 的目录放在：

```text
~/.codex/skills/wei-review-response/
```

## 调用示例

```text
请使用 $wei-review-response，按魏老师的返修风格修改下面这段英文回复。
保留事实与证据强度，明确实际修改位置，并用中文列出必要的核实项。
```

## 文件

- `SKILL.md`：触发条件、风格规则、工作流程及证据边界。
- `agents/openai.yaml`：Codex技能名称和调用提示。
- `references/style-evidence.md`：写作模式及适用边界。
- `references/rewrite-examples.md`：六类场景的改写示例。

## 来源范围

本仓库只分发通用规则与教学示例，不包含未发表稿件、原始批注、实验数据或本机文件路径。示例中的事实均有明确前提，不应直接用于真实论文。技能并非导师署名或官方认可的作品。
